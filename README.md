# 📊 Civic Issue Dashboard

A Power BI dashboard to monitor and analyze civic issues like garbage dumps, drainage leaks, potholes, water pipe bursts, and street light problems across different areas. It provides interactive visualizations, key metrics, and trends to help city authorities track and resolve issues efficiently.

## ✅ Features
- 📋 **Total Reports** – Shows the overall number of reported civic issues.
- ⚠️ **Active Areas** – Highlights areas with current problems.
- ⏱️ **Days Since Last Report** – Tracks how long it's been since the last reported issue.
- 🗂️ **Issue Types** – Categorizes issues for better management.
- 📊 **Reports This Year** – Displays trends and patterns in reported issues.

- Interactive charts with filters by area and severity.
- Time-based analysis of reports.
- Easy-to-read interface for faster decision-making.

## 📂 Tools Used
- **Power BI** – For building interactive visual reports and dashboards.

## 📌 Use Case
This dashboard assists municipal bodies and planners in identifying problem areas, prioritizing maintenance, and improving urban services based on data insights.

## 📥 How to Access
1. Download the `.pbix` Power BI file from this repository.
2. Open it using Power BI Desktop.
3. Connect to your dataset or use the sample data provided.

## 📂 Dataset
The dashboard uses a dataset with the following columns:
- `Report_ID`
- `Area_Location`
- `Issue_Type`
- `Severity`
- `Report_Date`

You can replace the sample dataset with your own civic issue data.
